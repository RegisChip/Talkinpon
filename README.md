# Talkinpon

**Talkinpon** es un sistema de **chatbot interactivo** diseñado para estudiantes, que permite realizar **consultas de carácter administrativo y sobre ubicaciones** dentro de la institución.  
El sistema se presenta como una **página web optimizada para tablets**.

---

## Características

- Chat interactivo que responde consultas administrativas y de ubicaciones.  
- Integración con reglas para procesar preguntas de los estudiantes.  
- Compatible con **React** o en el front-end y **Django** en el back-end.  
- Diseño adaptado para **tablets**, con interfaz amigable y responsiva.  

---

## Tecnologías

- **Back-end:** Python, Django  
- **Front-end:** React 
- **Base de datos:** PostgreSQL
- **Servidores:** NGINX y Gunicorn
- **Control de versiones:** Git & GitHub
